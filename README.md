## 💡 Overview

**TAXYNC** solves the complex tax regime selection problem for Indian salaried employees, software engineers, founders, and creators. Instead of static slab lookups, TAXYNC operates as an intelligent advisory system that:
1. Computes the **exact mathematical break-even deduction gap** required for Old Regime to beat New Regime.
2. Applies **Section 87A Marginal Relief** safeguarding taxpayers from punitive tax jumps when income slightly exceeds ₹12 Lakhs.
3. Quantifies the **rupee impact of Corporate NPS (Section 80CCD(2))** salary restructuring.
4. Models the **15–20 year compounded wealth gap** generated by redirecting monthly tax savings into disciplined index equity SIPs.

---

## ⚡ Key Architectural Capabilities

### 1. Dual-Regime Precision Engine
* **New Regime (Section 115BAC)**: Enhanced ₹75,000 standard deduction, revamped slabs (0-4L, 4-8L, 8-12L, 12-16L, 16-20L, 20-24L, >24L), and Section 87A rebate providing **₹0 tax liability up to ₹12 Lakhs** taxable income.
* **Section 87A Marginal Relief**: Prevents cliff-edge taxation by capping tax liability at the exact excess income above the ₹12 Lakh threshold.
* **Old Regime (Chapter VI-A)**: Enforces statutory caps on Section 80C (₹1.5L), Section 80D (₹25k/₹50k/₹1L), Section 24(b) Home Loan (₹2L), HRA metro/non-metro rules, Section 80E, 80U, and 80GGC.
* **HNI Surcharge Support**: Automatic computation of 10%–25% surcharge for taxable incomes exceeding ₹50 Lakhs with 4% Health & Education cess.

### 2. Strategic Tax Advisor & March 31 Action Plan
* **Two Hero Cards**: Eye-catching cards on the main dashboard providing live, calculated previews of tax-saving opportunities.
* **Independent Slide-Over Drawers**: Full-height, glassmorphic drawers mounted via React Portals with smooth spring physics (`x: 0` from `100%`), backdrop blur, and Lenis scroll desync prevention.
* **March 31 Statutory Countdown**: Live day-by-day deadline tracker and readiness progress bar monitoring HRA landlord PAN verification, Section 80C headroom, and Section 112A equity harvesting.

### 3. On-Device Payslip & Form 16 Scanner
* **Client-Side Privacy**: High-accuracy PDF/image text extraction running entirely in the client browser. Sensitive salary information is **never transmitted to any remote server**.
* Automatically populates Basic Salary, HRA, EPF (80C), and allowances in under 400ms.

### 4. Wealth Compounding & SWP Engine
* **Compounded Future Value**: Models the opportunity cost of tax savings via monthly SIPs at 12% CAGR across 5, 10, 15, and 20-year horizons:
  $$FV = P \times \frac{(1 + r)^n - 1}{r} \times (1 + r)$$
* **Systematic Withdrawal Plan (SWP)**: Computes safe monthly retirement cashflow and portfolio longevity.

### 5. Multi-Format Audit Export
* **Audit-Ready Excel (`.xlsx`)**: Generated server-side using OpenPyXL with formatted number accounting, live formulas, and side-by-side comparison tables.
* **Official PDF Summary**: Formatted multi-page tax certificate via ReportLab.

## 💻 Local Development Setup

### Option A: 1-Click Launch (Windows)
Simply double-click **`start.bat`** in the repository root. Both the FastAPI backend (`:8000`) and the Vite frontend (`:5173`) will launch automatically in separate terminal windows!

---

### Option B: Manual Setup

#### 1. Backend Service
```bash
cd backend
python -m venv venv

# Windows
.\venv\Scripts\activate
# macOS/Linux
source venv/bin/activate

pip install -r requirements.txt
uvicorn main:app --host 127.0.0.1 --port 8000 --reload
```

#### 2. Run Tax Engine Test Suite
```bash
cd backend
python tests/test_tax_cases.py
```
*Output: `ALL 7 INSTITUTIONAL TAX CALCULATION TESTS PASSED (100% ACCURACY)`*

#### 3. Frontend Service
```bash
cd frontend
npm install
npm run dev
```
Open **`http://localhost:5173`** in your browser.
